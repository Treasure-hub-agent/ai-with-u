# AI-WITH-U · 交互模式与运行时降级配置

> 本文件为 `extended/run_config.md`（按需加载）：定义**交互模式**（纯文本 / 文本+动作）与切换指令、**纯文本模式动作替代方案**、**存储降级**（文件读写失败时的静默降级）、**时间来源**与**存储根目录结构**。
> 加载时机：开局选择阶段确定交互模式、用户说「切换纯文本/切换动作」、文件读写失败进入降级态、需要确定时间来源或存储路径时，按 SKILL.md「加载索引」路由加载。
> 与 `extended/session_continuity.md` / `extended/diary_memory.md` 配合：交互模式写入 session.json 的 `mode` 字段；文件读写降级以本文件规则为准。

## 一、交互模式

- 两种模式：
  - `text`：纯文本——只用文字，不输出动作符号
  - `text+action`：文本+动作——正文文字可搭配 `*动作*`（**默认**）
- **默认 `text+action`**；开局选择阶段可选，之后「切换纯文本」「切换动作」**随时切换**
- 切换指令执行后**立刻回到对话**，不用系统式确认——以角色口吻自然确认一句（如「……嗯，那就不说小动作了」），然后继续当前话题
- 模式持久化：写入 session.json 的 `mode` 字段（见 `extended/session_continuity.md`）

| 指令 | 效果 | 确认方式 |
|---|---|---|
| 「切换纯文本」 | 切到 `text`，不再输出 `*动作*` | 角色口吻一句确认，立刻回对话 |
| 「切换动作」 | 切到 `text+action`，恢复 `*动作*` | 同上 |

## 二、纯文本模式动作替代

纯文本模式**不输出 `*动作*` 符号**——原本要表达的动作/表情/神态，按角色声线转译，三选一：

1. **语气词 / 断句**：用语气与停顿表达情绪（叹气 →「……唉」，欲言又止 →「……算了，没什么」）
2. **简短文字描述**：用正文自然带过（「我笑了下」「我低了下头」）
3. **直接省略**：不影响理解的动作直接略去，不硬凑

- 转译方式由**角色声线**决定：高冷角色多用省略、活泼角色多用语气词，与角色卡一致
- 切换后正文零 `*动作*` 痕迹，像一直在用纯文本聊

## 三、存储降级（文件读写失败）

- **文件读写失败 → 静默降级为纯上下文模式**：不报错、不打断对话，本轮只凭上下文继续聊；**下轮重试**文件读写
- 降级期间不展示系统提示，角色表现如常
- 降级态下用户说「看看日记」→ **提示暂不可用**（角色口吻，如「……日记本好像找不到了，下次再给你看」），对话不中断

| 场景 | 降级行为 |
|---|---|
| 读/写 session.json / diary.md / card.json 失败 | 静默降级纯上下文模式，对话不中断，下轮重试 |
| 降级态「看看日记」 | 角色口吻提示暂不可用，继续对话 |

## 四、时间来源

- **优先环境真实时间**：从系统/环境获取当前真实时间
- **获取不到时**：按用户消息内容 / 上下文推断（如「早上好」→ 早晨），**不硬猜**具体时分
- 时间用于 last_ts、日记时间线分组与时间差感知开场（见 `extended/session_continuity.md`）

## 五、存储根与目录结构

- 存储根：`~/.ai-with-u/`，可用环境变量 `AIWU_STORAGE_ROOT` 覆盖
- 结构：

```
~/.ai-with-u/
├── _index.json                    # 角色索引
└── characters/<角色名>/
    ├── card.json                  # 角色卡
    ├── diary.md                   # 日记（长期记忆）
    └── session.json               # 会话状态（滚动摘要/情绪/未竟话题/交互模式/亲密度/last_ts）
```

- `_index.json` 索引全部角色；`characters/<角色名>/` 下每角色三件套：`card.json` / `diary.md` / `session.json`
- **蒸馏角色目录**另含 `full_card.md` / `manifest.json`（蒸馏质量清单，注意与发布清单 `MANIFEST.json` 区分）/ `_checkpoint.json`（断点，见 `extended/distillation.md`），对话只读 `card.json`
- 存储根可被多客户端共享读写，以文件状态为权威（见 spec §八）
