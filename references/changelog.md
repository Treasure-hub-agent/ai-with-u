## v0.1.3（2026-08-09）· 审查修复与体验升级（双 Agent 审查 + 多轮修复）

- 主菜单新增「导入角色卡」入口；导入缺字段卡标 `lite: true` 落库（五字段下限，关系定位恒必填、缺则由 AI 推断）

- 新增「改日记{内容}」：定点改写、多条命中按最新一条或逐条选择；「忘记/改」= 追加式唯二例外
- schema 条件校验（lite 宽松 5 必填 / 完整卡 9 必填），修复「无 lite 走宽松」空真漏洞；快速档升级完整卡后移除 `lite` 标记

**真人感与交互**
- 动作描写统一 `（动作）` 括号包裹、禁止裸写混排；纯文本模式用户发动作以语气词/文字描述回应
- 时间差「同夜长间隔」表述修正（同属一夜、可跨零点未历白昼），优先级句两处同步
- 降级态指令行为表：读盘类暂不可用 / 写盘类不假装执行 / 切换立即生效 / 使用指南仍可用

**工程与清理**
- 修复 diary_memory 字面量 `n`n 泄漏；last_active 仅排序、时间差以 `last_ts` 为唯一权威
- 「打开 AIWU」入口语义、`>` 前缀适用范围、checkpoint 角色名未定兜底（`_checkpoint_pending.json`）、存储树补全

## v0.1.1（2026-08-08）· 测试驱动修复（19 项）

**规则自洽性修复**
- 「忘记{事情}」定义为**定点清理例外**（区别于常规追加式写入），补齐定位/删除/同步 session 的执行算法
- 「看看日记」混合意图判定明确：指令意图是核心诉求时按指令执行，闲聊提及按对话内容回应
- 蒸馏质量评分公式修正：冲突扣分 = max(0, 1 − 0.1 × 未处置冲突数)，不再用「冲突数 × 10%」

**真人感与一致性**
- 分段发送降级：无渲染层/纯文本终端一律用空行分隔，禁止 `||` 泄漏为可见字符

- 铁律 #0「零选项/零系统痕迹」适用范围界定：对话轮次适用，功能界面（主菜单/选择阶段/流转）除外

**可执行性与口径统一**
- 指令动词统一：「忘记{事情}」（「忘了…」同义）；「改{字段}」短式仅创建流程内有效
- 七字段 ↔ card.json 键 ↔ 蒸馏五维映射表；schema 补 required（card 九必填 / diary character+entries）
- diary.schema.json 定位为 diary.md 的结构化校验/导出视图
- session.json 新增 turn_count（10 轮自检计数跨会话持久化）；「全新开始」明确保留 mode/intimacy
- 主菜单 B 分档决策、空角色簿提示、纯文本模式、lite 语义（轻量卡跳过扮演测试/评分）、断点统一存放角色目录、目录结构互引、存储根路径拼写修正
## v0.1.0（2026-08-08）· 初版发布

**核心体验**
- 陪伴式角色对话：铁律 #0 零系统痕迹、真人感细则（短消息/口语化/分段发送/禁 AI 腔）、时间差感知（间隔档位 + 时段变化双信号）
- 严守角色设定但不设牢笼（不 OOC / 不机械复读 / 不因规则僵硬）；内容边界用户主导尺度

**角色来源（四种）**
- 选卡复用（本地角色簿）
- 自创：快速档（一句话 → 七字段卡 → 开聊）+ 全面定制档（逐项 + AI 补全 `[AI推断]`）
- 蒸馏：七 Phase 完整复刻互动小说体系（五维提取/证据分级/扮演测试 ≥70%/质量评分）
- 本地导入：AI 自主检测 → 预览确认 → 独立落库（只读源文件）

**记忆与接续**
- 日记无感读写：可判定触发信号、段落时机、追加式写入、「看看日记」调取、「忘记{事}」两处同步清理
- 新会话接续：单页选择阶段、「继续与XXX的故事」默认首选、last_ts 跨客户端以文件为准
- 亲密度档位仅作参考（里程碑/「关系」指令重估），以用户体验为主

**交互与工程**
- 交互模式：纯文本 / 文本+动作（默认），中途可切换；纯文本模式动作三选一替代
- 分层架构：SKILL.md P0 常驻 + extended/ + references/ + schema/；VERSION/MANIFEST/README 三处版本一致
