# 更新日志

## v0.1.7（2026-10-03）· 你的身份与轻量关系

**新的：你的身份（选填）**

- 角色卡新增附字段「**你的身份**」（`user_persona`）：可以把自己设成 TA 故事里的某个人（比如同一部作品里的另一位），也可以自己描述一句；**留空就是「你本人」**——不设也照常聊
- 四种来源都接得住：蒸馏收尾顺带一问（候选直接取自本次提取出的关系网络，说「可以了」就跳过）、自创一句话里提了就写（没提不追问）、定制档并入「关系」那一轮、导入时源卡写了你的身份就一并映射
- 随时可改：「改{角色名}的你的身份」；「角色卡」展示多一行，为空则省略
- 边界：素材不足标 `[待补]` 由你补，不编造、不自行联网；身份设定不改角色自身设定

**新的：故事背景（选填，故事感来源）**

- 角色卡新增附字段「**故事背景**」（`world`）：角色的**来处与落差**——他曾经是谁 / 因何落到今天 / 如今靠什么过日子 / **你与他的旧**；让角色带上**故事感**，避免只有性格标签的单薄卡
- **是底色，不是主线**：只作可聊的谈资与人生厚度，**不设时间表、不派任务、不制造必须解决的悬念**——本 skill 是纯聊天（剧情主线是互动小说那边的事），背景事件只在被聊到时出现，用户随时可以岔开
- 故事感三条：**有来处**（曾经的位置与今天的落差）、**有痕迹**（落差在日常里留下的习惯与避讳）、**与你有旧**（你们的关系带着这段背景）
- 来源：蒸馏把原作的来处与处境作底色收编（原主线不进对话、世界观不进五维）、自创由 AI 按角色落差补一段、导入从源卡 `scenario` / 世界观段落映射

**公开面命名**

- GitHub / npm 面向表述改为「**给你的 AI 装上角色扮演与长期记忆**」，去掉「聊天搭子」与手机 / app 化措辞（本 skill 是给 AI 用的 skill，不是手机应用）

**轻量关系**

- 亲密度收敛为「**模型按日记与近况现算**」的五档（陌生 / 认识 / 熟悉 / 亲近 / 亲密）纯呈现：**非数值、不落盘、无进度条**；只在主菜单 / 角色簿 / 选角 / 「关系」指令以档位标签出现，**对话里不出现**

**张力写法进规则（开场白的印象很重要）**

- 新增「张力写法」口径（`character_card.md` §1.5）：卡面要给角色一个**当下的利害**（正在做的一件有后果的事、没说出口的目的、关系里的暗流），开场白**第一条即钩子**——角色正在做事并主动开口，顺手把下一步摊给你；禁「静态场景 + 一句问候」
- 配套红线：**破折号清零**（AI 味标志）、不写静态景物扫描、不靠形容词堆情绪；`openings` 三句要拉开互动层级
- **分工写清**：自创卡「设定 + 开场白」双管（AI 补全**必须补出当下的利害**，不许落平淡卡）；蒸馏卡设定取自原作，**张力主要落在开场白**；导入卡开场平淡则按该口径重写
- 真人感细则与禁止词库同步补「开场钩子」「破折号与散文腔」两条去 AI 味项

**开箱即聊**

- 随包自带 3 张预置角色卡（日常治愈 / 活泼直率 / 高冷内敛三种声线原型），首次加载**幂等落位**：角色簿已有内容时绝不注入、同名不覆盖、删掉不复活，与自建卡同库同权、不加任何标签

**可执行性修复（24 项）**

- **存储根口径统一**：全文「存储根」单点定义，索引改存相对路径（换根/迁移后仍有效），补卡库自检（索引缺失或损坏时扫描重建，损坏卡保留并提示，不静默丢卡）
- **开局判定明确三态**（无档案 / 全新开始之后 / 有档案），消解「日记保留」与「重发初次开场」的自相矛盾：全新开始后跳过首句开场，按记忆与时间差自然接话
- **同夜长间隔**改为可判定边界（两端都落 20:00–06:00 夜间窗且间隔 < 8 小时，否则按跨夜算）；补**用户本地时区**口径
- **到期兑现**补两点写入要求（相对日期就地绝对化、注明生日/纪念日或一次性约定）与年度重复语义（按月日匹配、每年最多提一次），并明确接续开场必做一次到期匹配（生日能被提起的唯一路径）
- **蒸馏落库时机统一**：Phase 4 只写文件不生效，正式落库（更索引、删断点、生成开场）统一在 Phase 6 点头后；断点续跑改为角色名未定时**就地续跑**，消除死循环
- 其余：开场白轮换与持久化口径、快速档确认即去掉 `[AI推断]`、空角色簿 E/C/D 入口口径、导入未给来源位置时不猜路径、删除后同名重建三选、「忘记」补覆盖角色卡字段、多客户端并发写最小合并规则、降级期待写承载与轮次自增、英文别名与 `README.en.md` 命令表逐行对齐

## v0.1.6（2026-09-30）· 情感确定性与记忆主权

> v0.1.5 未单独发布，其改动并入本条（对外版本线 v0.1.4 → v0.1.6）。

**记得住，也提得起**

- 日记新增「到期兑现」：约定、生日与纪念日到期前后，角色按声线自然提起，判定靠 diary 日期 + 条目文字 + 环境日期，不加新机制、不加新文件
- 日记条目加最轻推进状态标注 `[事实]` / `[在推进]` / `[完结]`，召回优先「在推进」；接续开场读取顺序明确（先 session 摘要，再翻命中段落），旧日记不回溯改写
- 真人感细则新增「情感推力」：在意 / 吃醋 / 嘴硬 / 主动提由人设自然流露，措辞 100% 由声线决定，只写正向指引、不写禁令

**体验补强**

- 开场白升级为「一句默认 + 2-3 句备选」（`openings`）：建卡按不同风格锚点备好，「换一句开场」从备选里换
- README 中英新增「记忆是你的」栏目：本地 markdown、可导出可备份、换 agent 带着走、不上云不注册

**更轻一点**

- **蒸馏不再做扮演测试**（从蒸馏流程跳进角色会出戏，2026-09-30 热修移除）：收尾改为一次「信息确认」——五维覆盖 / 证据覆盖度 / 待定冲突列清，用户点头即落库开聊；质量评分同步去掉「测试通过率」项，保持可选
- 指令确认语、动作括号格式各收敛为单点权威 + 引用；常驻分段发送写法压缩（默认空行，分隔符在宿主支持渲染时可选）

**以下为 v0.1.5 改动（随本版一并发布）**

**规则一致性**
- 时间差感知补全优先级：同夜长间隔规则优先于时段问候，消除叠判歧义

- lite 轻量卡三来源口径统一（`extended/character_card.md` §1.4）：同一判定、同一行为、同一升级规则
- 关系里程碑清单收敛 `extended/diary_memory.md` 一处；「必记类」明确可即时追加；核心事实「不得改写」补用户「改日记」例外
- schema 补齐字段说明与约束（diary 日期格式 / entries 必填 / card 七字段描述），与文档映射明确

**开源合规（对齐版权与免责声明规范）**

- **内容尺度决定权交还用户**：移除内置尺度限制与此前口径（相关表述一并删除），亲密与 NSFW 剧情不设限，角色反应由人设与关系决定，不内置审查、门控与拒绝模板

## v0.1.4（2026-09-28）· 精简与修复

**整理版：不加新功能，把规则收敛回「陪伴聊天」本身**

- **规则收敛**：关系演化由「角色人设 + 日记记忆 + 时间差感知」自然承载；亲密度保持轻量背景参考（不显示数值、不手动调节）
- **指令收敛**：「关系」指令 = 角色口吻说说你们现在的关系状态（查看时重估档位，仅展示不写回）
- **条文去重**：时间差判定表 / 指令确认语 / 存储根声明等跨文件重复条文各归一处，改一处不再需要同步 N 处
- **首次登场**：建卡（自创 / 蒸馏 / 导入）完成后角色先说一句开场白（写入卡内 `opening`，仅在无历史存档的全新开始时使用，**单独成条**）；建卡完成后的去向改为一句自然提示，不再列 A/B/C 菜单
- **对话质量补丁（极简）**：禁止词库补「回避与越权」两条（不拿省略号/换话题当回复；只写自己的动作台词，不替用户代言）；日记补「用户核心事实记入即稳定、不得改写」；`topic` 明确覆盖未到期约定与待办
- **触发词拆分**：蒸馏断点续跑用「继续蒸馏」，与对话续聊的「继续」各走各的；指令表补「彻底重置」独立条目（二次确认）
- **审查整改**（逐项审查后修正）：旧卡无 `opening` 时首次见面即时生成并落库；新建同名角色**先问用户**、不静默覆盖；存储根声明归 P0 一处；「回避」禁令加限定（省略号作声线停顿照用）；英文别名落地并可触发（与 README.en 命令表对齐）；安装说明补 `-g` 与装后自检；用户面补「彻底重置」「换一句开场」；npm 包补 `CHANGELOG.md`；隐私与适用对象口径修正（`0` 到 `0` 的联网边界、面向成年用户）
- **修复**：package.json description 去掉「免费」字眼，与 README 的「开源」口径统一

## v0.1.0（2026-08-08）· 初版发布

**核心体验**
- 陪伴式角色对话：铁律 #0 零系统痕迹、真人感细则（短消息/口语化/分段发送/禁 AI 腔）、时间差感知（间隔档位 + 时段变化双信号）
- 严守角色设定但不设牢笼（不 OOC / 不机械复读 / 不因规则僵硬）；内容边界用户主导尺度

**角色来源（四种）**
- 选卡复用（本地角色簿）
- 自创：快速档（一句话 → 七字段卡 → 开聊）+ 全面定制档（逐项 + AI 补全 `[AI推断]`）
- 蒸馏：七 Phase 蒸馏体系（五维提取/证据分级/扮演测试 ≥70%/质量评分）——**当时口径**；v0.1.6 起收敛为六 Phase 并取消扮演测试
- 本地导入：AI 自主检测 → 预览确认 → 独立落库（只读源文件）

**记忆与接续**
- 日记无感读写：可判定触发信号、段落时机、追加式写入、「看看日记」调取、「忘记{事}」两处同步清理
- 新会话接续：单页选择阶段、「继续与XXX的故事」默认首选、last_ts 跨客户端以文件为准
- 亲密度档位仅作参考（里程碑/「关系」指令重估），以用户体验为主

**交互与工程**
- 交互模式：纯文本 / 文本+动作（默认），中途可切换；纯文本模式动作三选一替代
- 分层架构：SKILL.md P0 常驻 + extended/ + references/ + schema/；VERSION/MANIFEST/README 三处版本一致
- 开源发布：MIT License（初版内容边界口径较保守，后于 v0.1.6 交还用户，见本文件 v0.1.6 条目）
